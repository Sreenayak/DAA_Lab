# Linear Search

## Overview

This program checks array elements in order until it finds the requested key or reaches the end of the array.

## Time Complexity

| Case | Complexity |
|---|---|
| Best | O(1), if the key is the first element |
| Average | O(n) |
| Worst | O(n) |

## Space Complexity

| Case | Extra space |
|---|---|
| Best | O(1) |
| Average | O(1) |
| Worst | O(1) |

## Conclusion

Linear search works on unsorted data and is easy to apply, but its running time grows linearly with the number of elements. The array in this program has a capacity of 100 elements.
