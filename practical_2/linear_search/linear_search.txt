Time Complexity:
Best Case: O(1)
Average Case: O(n) 
Worst Case: O(n) 


Space Complexity:
O(1) 


Conclusion:
       Linear Search is a simple and straightforward searching algorithm that checks each element of an array
sequentially until the target element is found or the end of the array is reached. It does not require the ar
ray to be sorted, making it suitable for searching in unsorted datasets. Due to its simplicity and ease of imp
lementation, Linear Search is commonly used for small datasets. However, for large datasets, more efficient se
arching algorithms such as Binary Search are generally preferred when the data is sorted.
