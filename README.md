# DAA_Lab

**Subject code:** `01AI0506`

This repository contains C implementations and sample outputs for Design and Analysis of Algorithms lab practicals 1–12.

Each `practical_N` folder groups source code, a compiled executable when present, an output image, and an algorithm note.

The notes describe each algorithm and its best, average, and worst time and space complexity.

PNG files show sample program output. Existing executable files can be run on Windows.
