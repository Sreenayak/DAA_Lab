Time Complexity
• Best Case    : O(n)
• Average Case : O(n²)
• Worst Case   : O(n²)

Space Complexity
• Auxiliary Space : O(1)

Conclusion:
       Insertion Sort is a simple and reliable sorting algorithm that is widely used 
for learning fundamental sorting concepts. It is stable, easy to implement, and works efficiently for small
or nearly sorted datasets. While it is not suitable for large datasets, its simplicity and low memory requirements 
make it an important algorithm and a valuable component in several advanced hybrid sorting techniques.
