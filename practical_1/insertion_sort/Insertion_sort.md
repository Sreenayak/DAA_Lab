# Insertion Sort

## Overview

This program builds a sorted prefix one element at a time, shifting larger values right to insert each new value in its proper position.

## Time Complexity

| Case | Complexity |
|---|---|
| Best | O(n), for an already sorted array |
| Average | O(n²) |
| Worst | O(n²) |

## Space Complexity

| Case | Extra space |
|---|---|
| Best | O(1) |
| Average | O(1) |
| Worst | O(1) |

## Conclusion

Insertion sort is in-place and works well for small or nearly sorted arrays. Its running time can become quadratic when many elements must be shifted.
