# Selection Sort

## Overview

This program repeatedly selects the smallest value from the unsorted portion of the array and swaps it into the next position.

## Time Complexity

| Case | Complexity |
|---|---|
| Best | O(n²) |
| Average | O(n²) |
| Worst | O(n²) |

## Space Complexity

| Case | Extra space |
|---|---|
| Best | O(1) |
| Average | O(1) |
| Worst | O(1) |

## Conclusion

Selection sort is an in-place algorithm with a simple implementation and few swaps. Its quadratic number of comparisons makes it best suited to small arrays.
